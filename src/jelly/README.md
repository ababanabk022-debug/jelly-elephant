# 果冻小象网页实现

这是独立小象网页的源码；面向使用者的启动与构建说明见[项目 README](../../README.md)。使用已构建的 `jelly-site/` 与本地服务时，脚本、样式和 GLB 分别从本机加载，无外部网络资源。`jelly-elephant.html` 是重新构建用的源入口。

## 互动和支撑

`physics.ts` 用弹簧计算按压、拉伸、转动惯性及耳鼻的延迟回摆；`support.ts` 使用质量、重力和四个单向弹簧阻尼足垫计算接触与反力。拖住上半身时，`deform.ts` 将拉伸量平滑分配给身体并保护脚底，松手后有衰减回弹。模型和眼睛共享同一 GPU 形变映射，耳朵使用实际导出的 `_EARWEIGHTS` 权重。它是可控的简化弹性模型，不是体积有限元模拟；极限拉伸时仍可能出画或在耳尖、尾巴处变尖。

滚轮、双指和页面按钮缩放；转动、按压、回弹、柔软度和自定义颜色通过 `main.ts` 管理。颜色保存在浏览器本地存储，用户可恢复默认值。尊重系统的减少动态效果偏好。

旋转模式下水平拖动环绕、垂直拖动连续调节俯仰（上限略低于 90°，避免极点翻转），键盘方向键可做同样的调整。`opacity.ts` 提供 20%–100% 的表面 alpha 混合，透明时使用同步形变的深度预写避免表面排序碎斑；该效果不计算真实光学折射。离屏散射使用不透明材质副本以保留深度数据，透明度也会影响眼睛和地面阴影。内部透光散射随不透明度平滑降低，使 100% 的外观看起来更扎实；100% 的材质关闭透明混合和透射。

## 材质与灯光

`look.ts` 配置影棚灯与不透明 `MeshPhysicalMaterial`；`lightTransport.ts` 用两张光源深度图近似模型内部光程，并在半分辨率处理深度约束的漫反射扩散，再与清晰镜面反射组合。这是实时散射近似，光程从第一层表面计算，未对空隙做深度剥离，也不是 Cycles 级体积求解。`cavity.ts` 对鼻孔材料边界做连续过渡；`contactShadow.ts` 根据实际形变网格生成接触阴影。

## 检查

`npm test` 验证四足支撑的力、力矩和回稳。浏览器检查脚本位于 `scripts/`，通过 `window.jellyZoo.snapshot()` 读取实际交互状态；数值通过不能替代多角度和动作的视觉评审。测试依赖、使用方法和仓库内可用图片以根目录 README 为准；历史评审记录见 `docs/JELLY_ART_REVIEW.md`。
